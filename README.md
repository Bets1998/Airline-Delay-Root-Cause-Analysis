# Airline Delay Root Cause Analysis

## What this project is about
Flight delays are frustrating, but they’re also full of patterns.  
This project digs into real flight data to figure out **why delays happen, which airlines are most affected, and when delays peak during the year.**  

I built an **Excel dashboard** that makes it easy to explore these insights with interactive filters and charts.

## Goals
- Spot the main reasons flights get delayed (weather, technical issues, crew, congestion, late inbound aircraft, airport operations).
- Compare how different airlines perform (IndiGo, Air India, Akasa Air, SpiceJet, Vistara).
- Track monthly delay trends (Jan–Jun).
- Give users a simple, visual way to explore the data.

## Tools used
- **Excel**: pivot tables, slicers, charts, and dashboard design.
- **Data cleaning**: structured raw flight delay records.
- **Visualization**: interactive dashboard for root cause analysis.

## What the dashboard shows
- Airline‑wise delay rates and cancellation percentages.
- Average delay minutes by cause (weather, crew, technical, etc.).
- Monthly delay trends to highlight seasonal pressure.
- Filters to drill down by airline or cause.

## Key takeaways
1. **Late inbound aircraft and technical issues** cause the longest delays.  
2. **Large hub airports** add congestion‑related minutes.  
3. The **airline selector** helps separate network vs carrier performance.  
4. **Monthly trends** show seasonal spikes, especially around March–June.  

## How to try it
1. Download the Excel dashboard from the `dashboard/` folder.  
2. Open it in Microsoft Excel (2016 or later recommended).  
3. Use the slicers and filters to explore delays by airline, cause, and month.
